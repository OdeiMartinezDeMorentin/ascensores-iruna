Cómo funciona

Las personas usuarias reportan si un ascensor está operativo o no. El estado mostrado se calcula dando más peso a los reportes recientes y a quienes tienen buena reputación. Si los reportes son contradictorios, se muestra "Reportes contradictorios".

Aviso

Este es un proyecto independiente y no está relacionado con el Ayuntamiento de Pamplona.

Uso responsable

La utilidad de esta web depende del uso responsable y cooperativo de quienes la utilizan. Por favor, reporta únicamente el estado real de los ascensores.

Privacidad

Se almacena un hash de tu dirección IP para prevenir abusos y calcular tu reputación al reportar. No se guarda tu IP real ni ningún otro dato personal. La información se retiene durante un máximo de 30 días.
