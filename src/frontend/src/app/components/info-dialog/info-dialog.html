Cómo funciona

Los usuarios reportan si un ascensor está operativo o no. El estado mostrado se calcula dando más peso a los reportes recientes y a los usuarios con buena reputación. Si los reportes son contradictorios, se muestra "Reportes contradictorios".

Aviso

Este es un proyecto independiente y no está relacionado con el Ayuntamiento de Pamplona.

Uso responsable

La utilidad de esta web depende del uso responsable y cooperativo de sus usuarios. Por favor, reporta únicamente el estado real de los ascensores.

Privacidad

Se almacena un hash de tu dirección IP (HMAC-SHA256) para prevenir abusos y calcular tu reputación como reportero. No se almacena tu IP real ni ningún otro dato personal. Los datos se retienen durante un máximo de 30 días.
